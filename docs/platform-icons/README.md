# Iconos de plataformas

Vectores identificativos de Simple Icons, convertidos a VectorDrawable monocromos y tintados con el tema activo. Se incluyen localmente, sin peticiones de red. Se conservan los SVG de origen y la licencia del proyecto en este directorio.

Origen: [Simple Icons](https://github.com/simple-icons/simple-icons). PlayStation, Nintendo, Nintendo Switch, Nintendo 3DS, Nintendo GameCube, Wii, Sega, Atari, Steam, Android y Apple proceden de la etiqueta `13.21.0`; Xbox y Windows de `11.15.0`. URL de cada original: `https://raw.githubusercontent.com/simple-icons/simple-icons/<etiqueta>/icons/<nombre>.svg`.

La licencia CC0 del conjunto se adjunta en `LICENSE.md`. Los nombres y logotipos identifican las plataformas de la colección; las marcas pertenecen a sus titulares y no implican afiliación. La licencia del conjunto no concede derechos sobre marcas.

`PlatformCatalog` reconoce nombres y abreviaturas habituales. Algunas generaciones comparten el emblema de su familia; el nombre completo identifica el modelo exacto. Las plataformas desconocidas conservan la insignia de iniciales. Una URL HTTPS personalizada tiene prioridad; si falla, se muestra el recurso local.
